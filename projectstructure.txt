## External Dependencies

### Runtime Dependencies
- jsPDF (^2.5.1)                # PDF generation library
- @fortawesome/fontawesome-free (^6.5.1) # Icons for the UI

### CDN-loaded Dependencies
- Font Awesome                  # Icon library
- Google Fonts                  # Comic-specific fonts
- JSZip                         # For file operations
- html2canvas                   # For converting HTML to canvas for export
- jsPDF (UMD version)           # PDF generation

### Development Dependencies
- Vite (^5.0.0)                 # Modern build tool and development server

## Application Structure

### Main Workflow Steps
1. Image Upload Page            # First step - import images
2. Layout Selection Page        # Second step - choose panel layout
3. Comic Editor Page            # Main editing environment
   - Editor Sidebar             # Image library
   - Comic Canvas               # Panel editing area
   - Properties Panel           # Editing controls

### Key Features
- Panel Layout System           # 20+ different panel arrangements
- Image Management              # Upload, organize, and place images
- Text Tools                    # Add and style text elements
- Multi-page Support            # Create comics with multiple pages
- PDF Export                    # Generate downloadable PDF files
- Background Styling            # Apply different styles to panels
- Responsive Design             # Works on various devices and screen sizes
